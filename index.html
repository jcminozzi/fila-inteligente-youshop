Triagem antes da fila do WhatsApp

À esquerda, o que o cliente vê ao pedir ajuda no app. À direita, o que chega para o time de Operações: prioridade, time certo, dados pessoais ocultos e um rascunho de resposta para revisar.

    Como a triagem decide

    1. Dados pessoais saem primeiro. CPF, e-mail, telefone e nome viram marcadores antes de qualquer análise. O console nunca mostra o dado original.
    2. Risco de chargeback vai para o topo. Se a mensagem fala em contestar no banco, estorno no cartão, golpe ou fraude, o ticket vira P1 e nada é respondido automaticamente.
    3. Cada caso cai no time certo. Saque e vitrine vão para Operações e Comercial; afiliação parada vai para Onboarding; pedido e reembolso vão para o Atendimento ao Comprador. O rascunho usa só o texto dos guias oficiais.
    4. Dúvida simples recebe o guia na hora. Se o cliente responder que não resolveu, o caso entra na fila humana com o resumo pronto, sem precisar explicar de novo.

    O que fica de fora, de propósito

    A triagem não libera saque, não aprova cadastro e não envia resposta em caso sensível sem um analista aprovar. Ela organiza a fila e adianta o trabalho; quem decide é o time.

    Nesta versão a classificação é feita por regras e palavras-chave, rodando inteira no navegador. O script triador_youshop.py no repositório faz a mesma triagem em lote e, se configurado, usa o Gemini só para reescrever o rascunho a partir do texto já anonimizado.
